# Claude Ultimate Enhancer

![License](https://img.shields.io/badge/license-MIT-blue)
![Language](https://img.shields.io/badge/language-JavaScript-yellow)
![Type](https://img.shields.io/badge/type-Userscript-orange)

All-in-one Claude.ai enhancement suite — theme engine, usage monitor, prompt library, auto-scroll, DOM trimmer, visual upgrades, keyboard shortcuts, and more.

## Features

- **Theme Engine** — Multiple dark themes with custom color schemes
- **Usage Monitor** — Track your Claude usage and rate limits in real-time
- **Prompt Library** — Save, organize, and quickly insert frequently used prompts
- **Auto-Scroll** — Automatically scroll to new responses as they stream
- **DOM Trimmer** — Remove unnecessary UI elements for a cleaner interface
- **Visual Upgrades** — Glassmorphism effects, shimmer animations, polished UI
- **Settings Panel** — Toggle all features independently with persistent storage

## Installation

1. Install a userscript manager ([Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/))
2. Install the userscript from the `.user.js` file in this repo
3. Visit [claude.ai](https://claude.ai) — enhancements activate automatically
